# superstore-sales- & profit Analysis Dashboard (Power BI)
## Project Overview
An interactive and dynamic business intelligence dashboard built in **Power BI** using the popular **Superstore sales** dataset. this project tracks revenue, profitability, regional distribution, and shipping performence to deliver actionable business insights for decision-makers.

## Key Business insights and features
**Executive KPIs:** Total Sales, Total Profit, Profit margin(%), Total orders, and Quantity sold.
**Geographical Performence:** Regional and state level profitability analysis to identify loss making territories.
**Product Hierarachy:** Category and subcategory level breakdown to highlights best selling vs underperforming items.
**Customer segmentation:** Analysis across consumer, corporate, and home office segments.
**Interactive capabilities:** Cross filtering, drill-through, and dynamic slicers (Region, category, year/Quarter).

--
##Tech stack & Skills
**BI Tool:** Microsoft Power BI Desktop
**Data Modelling:** Star Schema design, Relationship (1-to-many)
**DAX Calculations:** Measures for total revenue, total profit,margin % ,year-over-year (YoY) Growth
**Visuals:** KPI cards, Donut Charts, Matrix Tables, Decomposition tree, Line & Clustered Bar Charts.
